# Reglas principales

- Los porcentajes consolidados se calculan como suma del numerador entre suma
  del denominador, nunca mediante promedio simple.
- Conversión y recuperación utilizan:
  Tienda + Año ISO + Semana ISO + ID/SKU + Color.
- Una venta posterior no se arrastra a otra semana, mes o año.
- Conversión máxima: 100%.
- Productividad inicial: 784 piezas por colaborador por día.
- Meta semanal de recorridos: 47 por tienda.
- Pendientes nunca negativos.
- Todas las consultas deben respetar el alcance del usuario autenticado.
