# Jerarquía de permisos

## Propietario del Sistema
- Hereda todos los permisos del Administrador.
- Puede administrar propietarios.
- Puede ejecutar acciones exclusivas del sistema.

## Administrador
- Puede cargar y procesar Excel.
- Puede configurar metas.
- Puede administrar usuarios no propietarios.
- Puede consultar Centro de Control y Diagnóstico.
- No puede crear, modificar ni eliminar al Propietario del Sistema.

## Consulta
- Solo consulta la información autorizada.
- No puede cargar archivos ni modificar configuración.
