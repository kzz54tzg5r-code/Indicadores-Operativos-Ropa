# V30 — Portafolio y navegación de Muertos y Cambios

- El Menú principal muestra proyectos generales, no indicadores individuales.
- **Muertos y Cambios** es el primer proyecto activo.
- Al abrir el proyecto aparece un menú interno permanente en la zona superior derecha.
- Se agregó **Volver al menú principal**.
- La pestaña interna seleccionada se conserva durante las recargas de Streamlit.
- El menú no depende del sidebar nativo y no puede desaparecer al ocultarlo.
- Se mantiene el alcance por módulo: Recuperación consulta todas las tiendas autorizadas; los módulos operativos usan las tiendas del proyecto.
