# PS Operaciones Ropa v17 Enterprise

Rediseño integral corporativo inspirado en SAP Fiori, Oracle Fusion,
Microsoft Fluent y Salesforce Lightning.

## Incluye
- Header blanco fijo con logo Price Shoes.
- Usuario fijo con saludo dinámico e iniciales.
- Sidebar azul oscuro fijo.
- 19 módulos funcionales o preparados para datos reales.
- Centro Ejecutivo, Operación Diaria, Semanal, Mensual, Productividad,
  Recuperación, Recorridos, Reportes, Centro de Control, Administración,
  Configuración de Metas, Carga Excel, Diagnóstico, Detalle Tienda,
  Detalle Colaborador, Histórico de Descargas, Alertas, Perfil e
  Inteligencia Operativa.
- Identidad visual única y consistente.
- Componentes implementables posteriormente con widgets estándar de Appsmith.
- Conserva procesamiento, caché, sesión, PDF y lógica FIFO de versiones anteriores.
